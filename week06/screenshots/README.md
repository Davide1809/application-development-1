
# Postman API Test Screenshots

- **POST:Product.png**: Creating a new product using POST /products with a JSON body. Shows the request and the resulting product in the response.
- **GET:Product.png**: Retrieving the list of all products using GET /products. Shows the paginated response with product data and metadata.
- **GET :products:id.png**: Retrieving a single product by ID using GET /products/:id. Shows the request and the product details in the response.
- **PATCH :products:id.png**: Updating a product using PATCH /products/:id. Shows the request with updated fields and the updated product in the response.
- **DELETE :products:id.png**: Deleting a product using DELETE /products/:id. Shows the request and the 204 No Content response.
- **POST:orders.png**: Creating a new order using POST /orders with a JSON body. Shows the request and the resulting order in the response.
- **GET:orders.png**: Retrieving the list of all orders using GET /orders. Shows the response with order data.
