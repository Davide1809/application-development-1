# Domain: Simple E-commerce (Products & Orders)

## What the system does
This system provides a RESTful API for a simple e-commerce platform. It allows clients to manage products, customers, and orders. Users can browse products, create orders, and view order history. The API handles core operations such as creating products, placing orders, and retrieving order details.

## Who uses the API
- Customers: Browse products, place and track orders.
- Admins: Manage products and view all orders.
